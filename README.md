# crysfipy - Tools for analysis of physical properties arising from crystal-field Hamiltonian

For list of modules and their descriptions see documentation at: 
(https://mstekiel.github.io/crysfipy)

Installation with `uv` python package manager
1. git: `uv add git+https://github.com/mstekiel/crysfipy@main`
2. local with edit option: `uv add --editable ../projects/crysfipy/`
